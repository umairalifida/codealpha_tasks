# 🧮 JavaScript Calculator

A clean and responsive calculator built with **HTML, CSS, and vanilla JavaScript**.

The calculator supports basic arithmetic operations, keyboard input, decimal calculations, error handling, and responsive UI.

## ✨ Features

* Addition `+`
* Subtraction `−`
* Multiplication `×`
* Division `÷`
* Modulo `%`
* Decimal calculations
* Clear button
* Delete button
* Real-time display
* Division-by-zero handling
* Keyboard support
* Responsive design
* Button hover and click animations

## ⌨️ Keyboard Support

| Key         | Function       |
| ----------- | -------------- |
| `0–9`       | Enter numbers  |
| `+`         | Addition       |
| `-`         | Subtraction    |
| `*`         | Multiplication |
| `/`         | Division       |
| `%`         | Modulo         |
| `.`         | Decimal        |
| `Enter`     | Calculate      |
| `Backspace` | Delete         |
| `Escape`    | Clear          |
