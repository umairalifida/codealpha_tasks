# 🖼️ Responsive Image Gallery

A modern and responsive image gallery built using **HTML, CSS, and JavaScript**.

The project demonstrates interactive image navigation, lightbox functionality, category filtering, hover effects, and responsive design.

## ✨ Features

* Responsive image grid
* Lightbox image viewer
* Next / Previous navigation
* Image category filters
* Hover effects
* Smooth transitions
* Keyboard navigation
* Mobile responsive layout
* Click outside to close lightbox
* `Escape` key support

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* DOM Manipulation

## 🎯 JavaScript Concepts

This project helped practice:

* DOM selection
* Event listeners
* Arrays
* Data attributes
* Dynamic filtering
* Keyboard events
* Image navigation
* Class manipulation
